# hardware-lab

[English](README.md) · **中文**

这是给 Claude 用的一个技能（skill）：你说出一样硬件，它帮你做一门零基础也能看懂的图解课。

硬件可以是一块开发板（树莓派 Pico、ESP32），也可以是一台成品（扫地机器人、Mac mini）。Claude 先查资料，把计划拿给你确认，再做成一个可以点着看的网页。语言可选中文、英文，或两种都要。

## 课程里有什么

| # | 章节 | 你会看到 |
|---|---|---|
| 1 | 外面 | 3D 模型，每个部件都有标注；这东西是做什么用的 |
| 2 | 里面 | 把部件拆开来看，每个部件在哪儿 |
| 3 | 每个部件做什么 | 每个部件一个可以动手试的小演示 |
| 4 | 部件怎么连起来 | 一张以主芯片为中心的线路图 |
| 5 | 跟着信号走 | 在线路图上一步一步看几个小故事 |
| 6 | 朝你的目标走一步 | 按你学习的目的设计的第一个小项目 |

每章最后有几道小测验。每个词都在用到的地方解释，不需要任何电子基础。

## 需要准备

- [Claude Code](https://claude.com/claude-code)（桌面应用或命令行）。
- Python 3，用来把课程拼成一个网页。
- 浏览器。打开课程时要联网，因为 3D 画面用的 Three.js 是从公共 CDN 加载的。

## 安装

```bash
git clone https://github.com/lulouise/hardware-lab.git
```

```bash
mkdir -p ~/.claude/skills && cp -R hardware-lab/hardware-lab ~/.claude/skills/
```

装好后新开一个 Claude Code 会话，技能才会生效。

## 怎么用

直接用自己的话告诉 Claude 你想弄懂什么：

> 我刚买了一块树莓派 Pico，完全不懂电子。能教我这块板子上都有什么、是怎么工作的吗？

Claude 分阶段做，中间停四次，请你在浏览器里看一看：计划、第 1–2 章、第 3–4 章、第 5–6 章。想一次做完，就说“全部做完再给我看”。一门完整的课要来回几个小时。

## 示例

`hardware-lab/examples/` 里有两门做好的课（课程文件）：

- `pico-course`：一块开发板（树莓派 Pico），带一个动手项目。
- `mac-mini-course`：一台成品（Mac mini M4），把芯片拆开细讲。

把示例生成网页：

```bash
python3 hardware-lab/kit/build.py hardware-lab/examples/pico-course
```

## 这一版的限制

- 只支持中文和英文，页面自带的文字只有这两种。
- 手机上，比较宽的线路图一屏放不下，需要用手拖着看。
- 暂不支持：根据一篇文章或一个问题做课、很抽象的主题（芯片设计、电网）、视频，以及老师或家长替别人做课。
- 课程里的事实来自 Claude 当时查到的资料，页面上列了来源和把握程度。接线或购买之前，重要的数字请再对一遍厂商的官方文档。

## 反馈

发现哪里讲错了、看不懂，欢迎在 GitHub 上提 issue。最有用的反馈是：具体哪一句话、哪一张图让你困惑。
